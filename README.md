# Webcam Puzzle Game 🧩

An interactive **AI-based Puzzle Game** built using your webcam, hand tracking, and computer vision (MediaPipe & OpenCV). In this project, you create a virtual frame in the air using your fingers, capture an image, and use gestures (pinch) to scramble and swap the puzzle pieces to solve it.

---

## 🛠 Features
* **Hand Tracking & Gesture Recognition:** Real-time interaction using your fingers.
* **Pinch to Scramble:** Pinch inside the frame to capture and mix the live video into a 3x3 grid.
* **Swap & Solve Logic:** Use pinch gestures to select and swap any two puzzle pieces to solve the challenge.
* **Organized & Lightweight:** Structured with a virtual environment so it can be easily pushed/pulled via GitHub.
